# fd-qicai-web — 启材线（教育）对外门面

启材线的官网与两个检索入口。定位是「**不灌输知识，而是让人和智能体找到当下需要的
素材、对正在做的事有参考效果**」——所以页面的核心不是介绍，而是**让人当场验证**：
许可可查、来源可回访、故障不伪装。

## 两个门（两类同级访客）

| 门 | 谁 | 他要做什么 | 页面要给的 |
|---|---|---|---|
| **A** 学生/老师 | 正在学一门课、备课、写综述 | 「当下能参考的素材」、订阅盯新料 | 能试检索 |
| **B** 智能体/开发者 | 让 agent 取可信素材、接入检索面 | 拿端点/工具面/许可契约 | 能照页面独立复现一次调用 |

「智能体是一等消费者」是定位核心，不是脚注——门 B 的信息完整度与门 A 同级。

## 跑起来

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # 产物在 dist/
```

## 目录

```
src/pages/index.astro        门面主页（两个门的入口）
src/pages/docs/mcp.astro     门 B 的接入文档（端点、工具面、许可契约）
public/  reports/            静态资源与构建报告
DESIGN.md                    设计与版式决策
PRODUCT.md                   定位、用户、产品目的的完整版
```

## 三份文档的分工

| 文档 | 回答 |
|---|---|
| `PRODUCT.md` | 它是干什么的、给谁用、成功怎么算 |
| `DESIGN.md` | 它是怎么搭起来的、为什么这么搭 |
| 本 README | 怎么跑起来、目录里有什么 |

## 部署

静态产物，由宿主 nginx 托管；部署清单在 `fd-infra-deploy`（本仓不放清单）。
